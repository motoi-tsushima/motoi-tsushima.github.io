2026年11月10日に `mfsr`・`mfprobe`・`rmsmf`・`txprobe` のバージョン 1.1.3 のリリースを開始したことを、ご報告します。

先日の SnowStack.EncodingProbe 1.3.0 のリリース時に伴い、クラスライブラリの入れ替えを行ったものです。

いつものように`mfsr`・`mfprobe`については、`winget`にて提供しています。

`winget upgrade`で更新可能なパッケージを確認し、`winget upgrade --all`でまとめて、または パッケージ ID を指定して個別に更新できます。

```
winget upgrade

winget upgrade --all

winget upgrade motoi.tsushima.mfprobe
winget upgrade motoi.tsushima.mfsr
```

新規にインストールする場合は、パッケージ ID を指定してインストールしてください。

```
winget install motoi.tsushima.mfprobe
winget install motoi.tsushima.mfsr
```

詳しいインストール方法の解説は以下のページで行っています。

[mfsr-mfprobe インストール解説](https://snow-stack.net/mfsr_install_guide/)

`rmsmf`・`txprobe`は、業務上 `.NET Framework 4.8`しか使用することが許されない方々のために提供しており、`winget`による提供はしておりません。

インストール方法は、以下のページで解説しております。

[rmsmf-txprobe インストール解説](https://snow-stack.net/rmsmf_install_guide/)

使用説明書は、以下の固定ページで以前から解説しております。

[rmsmf-txprobe & mfsr-mfprobe 使い方の分かりやすい解説](https://snow-stack.net/tool_rmsmf_guide/)

## 1.1.2 リリース内容

`mfsr`・`mfprobe`・`rmsmf`・`txprobe` は全て、`SnowStack.EncodingProbe`クラスライブラリを使用して文字エンコーディング解析を行っています。

先日、このクラスライブラリを`1.3.0`にアップデートしたので、こちらのコマンド群にも最新版クラスライブラリを導入してリリースしたものが、`1.1.3`になります。

`mfsr`・`mfprobe`・`rmsmf`・`txprobe` は全て、クラスライブラリを最新版にアップデートしただけで、基本機能や使い方に変更はありません。

### 変更点

`mfsr`・`mfprobe`・`rmsmf`・`txprobe` について、クラスライブラリのアップデートにより、変わった部分があります。

クラスライブラリの変更内容は、以下の固定ページで詳しく解説しています。

[SnowStack.EncodingProbe 1.3.0 解説 — CSV の読み書きと、文字を失わない書き込み](https://snow-stack.net/encodingprobe_1_3_0/)

リリースの告知は、[SnowStack.EncodingProbe.PowerShell 1.3.0 リリースのお知らせ]({% post_url 2026-10-31-encodingprobe_powershell_1_3_0_提供_お知らせ %})の記事で行っています。

上の「SnowStack.EncodingProbe 1.3.0 解説」の「判定の修正（クラスライブラリ）」で報告しているクラスライブラリ`SnowStack.EncodingProbe`の変更点は、今回の`mfsr`・`mfprobe`・`rmsmf`・`txprobe` の`1.1.3`にも反映されています。（PowerShellコマンドレット固有の機能は除きます）

変更したのは、参照しているクラスライブラリ`SnowStack.EncodingProbe`のバージョンだけで、コマンド本体のコードは変更していません。

よって、使い方も変わりません。



以上、リリースの報告でした。
